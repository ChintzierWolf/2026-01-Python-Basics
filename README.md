# 🐍 2026-01 Python Basics

¡Bienvenido al repositorio **2026-01 Python Basics**! 🚀

Este proyecto es un espacio de estudio personal dedicado al aprendizaje progresivo del lenguaje de programación Python. Está diseñado para ir desde los conceptos más básicos para un principiante, hasta alcanzar la preparación necesaria para aprobar la certificación **PCEP (Certified Entry-Level Python Programmer)** del Python Institute.

---

## 📂 Estructura del Repositorio

El repositorio está organizado en dos secciones principales, pensadas para separar el aprendizaje general del lenguaje, de la preparación específica para el examen de certificación:

### 1. 📘 `2026-01-Fundamentos-De-Python`

Esta sección está estructurada bajo una metodología de aprendizaje práctico. Contiene todo lo necesario para aprender a programar desde cero y se divide en tres fases:

- **`01.Learn/` (Aprender):** Teoría, apuntes, conceptos clave y ejemplos de código con comentarios explicativos.
- **`02.Doing/` (Hacer):** Ejercicios prácticos de seguimiento para aplicar inmediatamente lo leído en la fase de aprendizaje.
- **`03.Practice/` (Practicar):** Retos de programación, problemas de lógica y pequeños proyectos para asentar el conocimiento y ganar fluidez.

### 2. 🎓 `Python-PCEP`

Esta carpeta es una ruta de estudio intensiva enfocada 100% en los temas del examen de certificación **PCEP-30-02**. Está dividida de manera cronológica para mantener el ritmo:

- **`semana-1/`:** Material de estudio, apuntes específicos del temario (syllabus) y pruebas correspondientes a la semana 1.
- **`semana-2/`:** Continuación del temario del PCEP, ejercicios de preparación y simuladores para la semana 2.

---

## 🎯 Objetivos del Proyecto

1. Dominar los fundamentos de la programación (estructuras de control, variables, colecciones, funciones, etc.) usando Python.
2. Obtener los conocimientos técnicos y la práctica necesaria para superar con éxito la certificación PCEP.
3. Crear una base de conocimiento o "guía de referencia rápida" propia que sirva para consultas en el futuro.

## 🛠️ ¿Cómo usar este repositorio?

El flujo ideal de trabajo diario consiste en:

1. Leer y comprender un nuevo concepto en la carpeta `01.Learn`.
2. Escribir y probar el código en `02.Doing`.
3. Consolidar lo aprendido sin ayudas externas en `03.Practice`.
4. Complementar la semana cubriendo los módulos correspondientes del temario oficial en la carpeta `Python-PCEP`.
